## 🔌 GitHub API 限制和付费

**免费版：**
- ✅ 认证账户：5000 请求/小时
- ✅ 未认证账户：60 请求/小时

**付费版：**
- ✅ 5000 请求/小时（与免费版相同）
- ✅ 无额外增加（付费不影响 API 限制）

**注意：**
- GitHub API 限制不会因为付费而增加
