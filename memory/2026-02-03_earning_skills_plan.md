**步骤 2：选择适合的投资产品（10 分钟）

**推荐投资产品（新手）：**
1. **定期存款：** 低风险、低收益（年化 2%-3%）
2. **货币基金：** 低风险、低收益（年化 2%-3%）
3. **指数基金：** 中等风险、中等收益（年化 5%-10%）
4. **债券基金：** 低风险、低收益（年化 3%-5%）

**新手建议：**
- 从定期存款或货币基金开始（熟悉投资流程）
- 再尝试指数基金（获得更高收益）
- 避免高风险投资（如股票、期货、加密货币）

---

**步骤 3：开始小额投资（10 分钟）

- **分散投资：** 投资多个指数基金（分散风险）
- **长期持有：** 长期持有（3-5 年），不要短期交易

**投资示例：**
```

```
