## 🚀 快速开始

### 1. 安装依赖

```bash
cd /root/.openclaw/workspace/ai_email_toolkit
pip install -r requirements.txt
```

### 2. 配置智谱 API Key

编辑 `app.py`，修改以下行：

```python
ZHIPU_API_KEY = "your-zhipu-api-key"  # 改成你的 API Key
```

### 3. 启动服务

```bash
python3 app.py
```

服务将在 `http://localhost:8083` 启动

## 📝 功能说明

### 核心功能

1. **生成营销邮件**
   - 输入产品名称和特点
   - 选择目标受众
   - 选择邮件类型
   - 选择语气风格
   - 自动生成吸引人的邮件内容

2. **批量生成邮件**
   - 一次生成多个版本
   - 选择不同的目标受众
   - 对比选择最好的版本

3. **多种邮件类型**
   - 促销邮件
   - 新品公告
   - 跟进邮件
   - 电子通讯
   - 重新激活

4. **多种语气风格**
   - 专业正式
   - 亲切友好
   - 轻松随意
   - 紧急促销
