## 🐛 Python 相关

### 问题 1：Selenium 安装失败

**时间：** 2026-02-02 10:20
**问题：** Python 系统包（attrs）与 pip 版本冲突
**错误：** `error: uninstall-no-record-file`
**解决方案：**
1. 使用虚拟环境（venv）
2. 使用 `--ignore-installed` 参数忽略系统包
3. 在虚拟环境中安装所有依赖

**经验总结：**
- ❌ 不要在系统 Python 中直接安装包
- ✅ 总是使用虚拟环境（venv 或 conda）
- ✅ 使用 `python3 -m venv` 创建虚拟环境
- ✅ 在虚拟环境中安装所有依赖

### 问题 4：Git Tag SHA 不完整

**时间：** 2026-02-02 11:00
**问题：** 提交 SHA 只有 12 个字符，需要 40 个
**错误：** `The object parameter must be exactly 40 characters`
**解决方案：**
1. 使用完整的 SHA（40 个字符）
2. 从 `git log -1 --format=%H` 获取完整 SHA
3. 不要使用简短的 SHA（`-short` 参数）

**经验总结：**
- ❌ 不要使用 `git log --oneline` 的短 SHA
- ✅ 使用 `git log -1 --format=%H` 获取完整 SHA
- ✅ 确认 SHA 长度为 40 个字符
- ✅ GitHub API 需要完整的 40 个字符 SHA

**时间：** 2026-02-02 07:15
**问题：** 服务器已经是 CST 时区，但代码中又加了 8 小时
**解决方案：**
1. 检查系统时区设置（`timedatectl`）
2. 如果服务器已经是正确时区，不需要再加偏移
3. 使用 `datetime.now()` 获取本地时间
4. 不要手动加时区偏移

**经验总结：**
- ✅ 首先检查系统时区设置
- ✅ 使用系统时间而不是手动计算
- ✅ 确认时间计算的逻辑正确
