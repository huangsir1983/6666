## 🛠️ 工具介绍

### 什么是 Claude Code？

**Claude Code** 是 Anthropic 公司推出的一款 AI 编程助手（类似 GitHub Copilot 或 Cursor）。它不仅是一个代码补全工具，更是一个强大的 **AI Agent**，可以：

1. **理解自然语言需求** - 你可以用自然语言描述你想要的功能，Claude Code 会帮你编写代码。
2. **分析代码和文档** - 它可以分析现有的代码库和文档，提取关键信息。
3. **生成和修改代码** - 它可以生成新代码、修改现有代码、调试 Bug。
4. **使用工具** - 它可以调用外部工具（如：Python 脚本、终端命令、网页搜索）来完成更复杂的任务。

### 为什么 Claude Code 适合做论文摘要？

1. **强大的文本理解能力** - 基于 Claude 3.5 Sonnet 模型，它对长文本（如：论文、技术报告）的理解能力非常强。
2. **支持超长上下文** - 它的上下文窗口高达 8192 tokens（约 6000-7000 个汉字），这意味着它可以一次性处理整篇论文。
3. **结构化输出能力** - 它可以按照你的要求，生成结构化的输出（如：JSON 格式、Markdown 格式、思维导图格式）。
4. **工具调用能力** - 它可以调用外部工具（如：Python 脚本）来处理更复杂的任务（如：从 PDF 中提取表格）。

## 🚀 如何使用 Claude Code 做论文摘要？

### 步骤 1：准备论文

**支持的格式：**
- PDF 文件（`.pdf`）
- Word 文档（`.docx`, `.doc`）
- Markdown 文件（`.md`）
- 文本文件（`.txt`）
- 网页链接（`http`, `https`）

**准备步骤：**
1. 将论文文件保存到本地电脑。
2. 或将论文的 PDF 链接准备好。

### 步骤 2：打开 Claude Code 并输入需求

**在 Claude Code 中输入以下自然语言需求：**

> **需求 1：摘要我的论文**
> 
> 请帮我摘要这篇论文：[论文文件路径或链接]。我需要你提取以下信息：
> 
> 1. **标题** - 论文的标题
> 2. **作者** - 论文的作者
> 3. **摘要** - 论文的摘要（150 字以内）
> 4. **关键点** - 论文的核心观点（3-5 个）
> 5. **研究方法** - 论文使用的研究方法（1-2 句话）
> 6. **主要结论** - 论文的主要结论（1-2 句话）
> 7. **思维导图** - 生成一个思维导图（Markdown 格式），展示论文的逻辑结构

> **需求 2：提取表格**
> 
> 如果论文中有表格（如：实验结果表格、对比表格），请帮我提取所有表格，并保存到 Excel 文件。

> **需求 3：分析参考文献**
> 
> 如果论文中有参考文献，请帮我提取所有参考文献，并生成一个引用列表（Markdown 格式）。

### 步骤 3：Claude Code 执行任务

**Claude Code 会执行以下操作：**

1. **读取论文文件** - 如果你提供的是文件路径，Claude Code 会读取文件。如果你提供的是链接，Claude Code 会访问链接并下载文件。
2. **分析论文内容** - Claude Code 会分析论文的标题、摘要、引言、正文、结论等部分。
3. **提取关键信息** - 根据你的需求，提取标题、作者、摘要、关键点、研究方法、主要结论。
4. **生成结构化输出** - 按照 Markdown 格式生成结构化的摘要。
5. **生成思维导图** - 生成一个 Markdown 格式的思维导图，展示论文的逻辑结构。

**输出示例：**

```markdown
# 论文摘要

## 标题
[论文标题]

## 作者
[作者姓名]

## 摘要
[论文摘要，150 字以内]

## 关键点
1. [关键点 1]
2. [关键点 2]
3. [关键点 3]
4. [关键点 4]
5. [关键点 5]

## 研究方法
[论文使用的研究方法]

## 主要结论
[论文的主要结论]

## 思维导图
- 根节点：[论文标题]
  - 分支 1：[章节 1]
    - 子分支 1：[关键点 1]
    - 子分支 2：[关键点 2]
  - 分支 2：[章节 2]
    - 子分支 1：[关键点 3]
    - 子分支 2：[关键点 4]
```

## 🎯 进阶技巧

### 技巧 1：使用 Claude Code Agent 进行自动化

**Claude Code 不仅是一个 AI 助手，还是一个 AI Agent。**

**你可以定义一个 Agent（AI 代理）来自动化你的工作流：**

1. **打开 Claude Code**
2. **点击左侧的 "Agents" 标签**
3. **点击 "New Agent"**
4. **输入 Agent 名称**：如：`DocSummarizerAgent`
5. **输入 Agent 描述**：如：`自动摘要论文并生成思维导图`
6. **定义 Agent 任务**：如：`读取用户提供的论文 -> 摘要论文 -> 生成思维导图`
7. **点击 "Create Agent"**

**之后，你只需要：**
1. 将论文文件拖拽到 Claude Code 中。
2. 在聊天框中输入：`@DocSummarizerAgent 摘要这篇论文`
3. Claude Code Agent 会自动执行所有任务。

### 技巧 2：使用 Claude Code 的 Skills (技能）系统

**Claude Code 支持插件式的技能（Skills）系统。**

**你可以安装自定义技能（Skills）来扩展 Claude Code 的能力：**

1. **搜索 Skills**：在 Claude Code 的 Marketplace 中搜索 "PDF extraction" 或 "Mind map"。
2. **安装 Skills**：点击安装按钮。
3. **使用 Skills**：在聊天框中输入 `@skill-name` 来调用技能。

**例如：**
- 安装 `PDF-Extraction-Skill` - 用于从 PDF 中提取表格和图片。
- 安装 `Mind-Map-Generation-Skill` - 用于自动生成漂亮的思维导图图片。

### 技巧 3：使用 Claude Code 进行批量处理

**如果你有 10 篇论文需要摘要，你可以：**

1. **编写一个简单的 Python 脚本**，使用 Claude Code 的 API（即将开放）。
2. **遍历所有论文文件**。
3. **对每篇论文调用 Claude Code API**。
4. **保存所有摘要到一个 Excel 文件**。

**示例 Python 代码：**
```python
import requests

def summarize_paper(file_path, api_key):
    url = "https://api.anthropic.com/v1/messages"
    headers = {
        "x-api-key": api_key,
        "content-type": "application/json",
        "anthropic-version": "2023-06-01"
    }
    
    # 读取论文文件
    with open(file_path, 'rb') as f:
        file_content = f.read()
    
    # 调用 Claude Code API
    data = {
        "model": "claude-3-5-sonnet-20240229",
        "max_tokens": 1024,
        "messages": [
            {
                "role": "user",
                "content": f"请摘要这篇论文，并生成一个思维导图：\n\n{file_content}"
            }
        ]
    }
    
    response = requests.post(url, headers=headers, json=data)
    return response.json()

# 批量处理
paper_files = ["paper1.pdf", "paper2.pdf", "paper3.pdf"]
summaries = [summarize_paper(f) for f in paper_files]

# 保存到 Excel
import pandas as pd
df = pd.DataFrame(summaries)
df.to_excel("summaries.xlsx", index=False)
```
