- **描述：** Build resilient language agents as graphs.
- **Stars：** 24,128 (高人气)
- **Forks：** 4,203
- **语言：** Python

**关键知识：**
- LangGraph 是一个用于构建有状态、循环的 AI Agents 的库。
- 它将 AI Agent 的执行过程抽象为一个图（Graph），节点是可执行的操作，边是状态的转换。
- 非常适合处理复杂的、多步骤的、有记忆的 AI 任务，比传统的链式调用更强大。
