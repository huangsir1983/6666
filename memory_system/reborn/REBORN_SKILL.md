## 🧠 什么是重生技能

### 定义

**重生技能：** 当 AI 重启、打开新窗口或从新系统恢复时，能够从 GitHub 或本地读取最新的记忆、任务和历史，快速恢复成“最新的 AI”。

### 重要性

1. **上下文连贯** - 保持对话和项目的连贯性
2. **快速恢复** - 几秒钟内恢复工作状态
3. **自我迭代** - 持续记录成长和经验
4. **无缝切换** - 在不同窗口、不同系统间无缝切换

---

## 🎯 重生技能的用途

### 场景 1：AI 重启

**描述：** 当 AI 进程重启或崩溃后

**问题：**
- 丢失了当前的对话上下文
- 丢失了当前的任务状态
- 丢失了之前的决策记录

**解决：**
- 从 GitHub 下载最新的记忆文件
- 恢复 SESSION_MEMORY、TASKS、CONTEXT、DECISIONS
- 继续当前的任务

---

### 场景 2：打开新窗口

**描述：** 当打开新的对话窗口时

**问题：**
- 新窗口没有之前的记忆
- 不知道当前的任务和进度
- 丢失了之前的决策和经验

**解决：**
- 从 GitHub 读取最新的记忆
- 恢复工作状态和任务列表
- 继续当前的项目

---

### 场景 3：从新系统恢复

**描述：** 当从新的操作系统或环境恢复时

**问题：**
- 新系统没有本地的记忆文件
- 不知道之前的任务和项目
- 需要重新建立工作环境

**解决：**
- 从 GitHub 下载所有记忆文件
- 恢复工作环境（Git、Python 等）
- 继续当前的项目

---

## 🎯 重生技能的最佳实践

### 1. 优先使用 GitHub 记忆

**原因：**
- GitHub 是最新的备份
- GitHub 有版本控制
- GitHub 可以从任何地方访问

**方法：**
- 每次重生，优先从 GitHub 下载
- 只有 GitHub 不可用时，才使用本地记忆

---

### 2. 完整恢复所有记忆文件

**原因：**
- 确保所有记忆都被恢复
- 确保没有丢失任何信息

**方法：**
- 恢复核心记忆（4 个文件）
- 恢复知识库（2 个文件）
- 恢复技能库（4 个文件）
- 恢复每日记录（3 个文件）

---

### 3. 验证恢复结果

**原因：**
- 确保记忆恢复成功
- 确保没有错误和丢失

**方法：**
- 对比恢复前后的记忆
- 检查文件数量和大小
- 检查关键信息是否正确
